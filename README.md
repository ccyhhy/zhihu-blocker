# 知乎批量拉黑 - Chrome 扩展

根据关键词规则自动批量拉黑知乎用户，支持拉黑关注者/粉丝、回答点赞者。

## 安装

1. 下载 `zhihu-blocker` 文件夹到本地
2. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
3. 打开右上角「**开发者模式**」开关
4. 点击「**加载已解压的扩展程序**」
5. 选择 `zhihu-blocker` 文件夹
6. 安装完成，浏览器工具栏出现插件图标

## 使用方法

### 一、关键词自动拉黑

> 适用于：浏览知乎时自动按关键词匹配页面上的用户并拉黑

1. 点击浏览器工具栏的插件图标，打开弹窗
2. 在「关键词规则」区域输入关键词（如 `营销号`），勾选匹配来源（签名/评论/回答/文章），点击「添加规则」
3. 打开知乎任意页面（首页、问题页、搜索结果等）
4. 插件会自动扫描当前已加载内容，并拉黑命中规则的用户
5. 继续滚动页面加载更多内容时，插件会继续自动扫描

### 二、自动模式说明

插件现在只保留自动模式，不再提供手动扫描按钮。每次打开弹窗可查看今日已拉黑数量、规则和当前页面可用的专项操作。

### 三、拉黑关注者/粉丝

> 适用于：一键拉黑某人的全部关注者或粉丝

1. 打开知乎某用户的关注者或粉丝页面（如 `zhihu.com/people/xxx/followers`）
2. 点击插件图标打开弹窗
3. 弹窗中自动出现「**拉黑关注者**」或「**拉黑关注的人**」按钮
4. 设置最多拉黑人数（默认 100），点击按钮后插件通过 API 翻页获取用户并逐个拉黑

### 四、拉黑回答点赞者

> 适用于：拉黑某个回答的所有点赞用户

1. 打开知乎某个回答的页面（如 `zhihu.com/question/xxx/answer/xxx`），或在首页信息流滚动到目标回答卡片。
2. 点击插件图标打开弹窗
3. 弹窗中自动出现「**拉黑该回答赞同者**」按钮；如果当前页面识别到多个回答，可先在下拉框中选择目标回答
4. 设置最多拉黑人数（默认 100），点击按钮
5. 插件通过 API 翻页获取全部点赞者，逐个拉黑

> 首页 `https://www.zhihu.com/` 使用时，如果没有看到按钮，先滚动到目标回答卡片，再点击弹窗里的「重新识别」。

### 五、评论喜爱者

知乎目前只稳定展示评论「喜爱」数量，尚未确认开放「喜爱者名单」接口。

因此插件暂不提供「拉黑评论喜爱者」功能，避免误导为可用能力。若后续通过浏览器 Network 抓到包含用户 `url_token` 的真实接口，再接入此功能。

## 设置说明

点击弹窗右上角「设置」，或在弹窗底部展开「设置」卡片：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| 拉黑间隔 | 每次拉黑之间的随机等待时间 | 0 秒 |
| 翻页间隔 | 获取关注者/点赞者列表时翻页等待时间 | 0 秒 |
| 并发拉黑数 | 拉黑间隔为 0 秒时同时发送的拉黑请求数 | 5 |

> 说明：当前版本没有「闪电」按钮。拉黑速度默认就是最快模式，间隔设置默认均为 `0 秒`，且不设置每日上限。

## 工作原理

- **拉黑方式**：调用知乎官方 API（`POST /api/v4/members/{url_token}/actions/block`），与手动点击「拉黑」按钮效果相同
- **拉黑是账号级别的**：被拉黑用户会出现在知乎「设置 → 屏蔽」列表中，可随时手动解除
- **自动去重**：已拉黑的用户不会重复拉黑
- **关键词自动扫描**：有规则时自动扫描当前已加载内容

## 卸载

1. 打开 `chrome://extensions/`
2. 找到「知乎批量拉黑」，点击「移除」
3. 已拉黑的用户不受影响，仍在知乎屏蔽列表中

## 注意事项

- 需要已登录知乎才能使用
- 关键词自动拉黑需要先设置关键词规则，否则不会触发
- 拉黑操作无法通过插件撤销，需到知乎「设置 → 屏蔽」手动解除
- 拉黑失败时会自动停止（不会重试），可能是网络问题或登录过期
